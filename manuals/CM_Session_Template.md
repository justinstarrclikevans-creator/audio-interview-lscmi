# Turn90 First Shift Case Management Session Template & Adherence Rubric

> [!CAUTION]
> **STRICT ANTI-HALLUCINATION & ZERO-EXAMPLE-LEAKAGE POLICY**
> 1. **Never pull or cite examples, names, or dialogue from any skill, manual, or reference file** as evidence in a participant or staff evaluation.
> 2. **Every claim, coaching observation, or behavioral match MUST be grounded in a verbatim quote** (`6–35 words`) with an `[MM:SS]` timestamp from the actual session transcript or explicit intake record.
> 3. Any quote that fails deterministic substring/trigram verification against the input transcript is immediately stripped.


## 1. The Official 6-Part First Shift Case Management Session Template
Every weekly 1-on-1 Case Management session must follow this 6-part structure:

1. **Part 1: Check-In & Stability Review (3–5 min)**
   - Review attendance, punctuality, drug test status, housing/transportation stability, and any immediate workplace or supervision (PO/court) issues.
   - *Rule:* If a Stability Issue occurred (2+ unplanned absences, any NCNS, smelling like MJ/alcohol, positive hard substance screen), follow the corresponding script in `./references/first_shift_conversation_scripts.md`.
2. **Part 2: Unified Briefcase & SkillCat Progress Review (5 min)**
   - Review the participant's Unified Briefcase dropdown items (especially any incomplete First Shift Waitlist / placement items: State ID/DL, SS Card, Birth Certificate, Chronic Health/Meds if applicable, Housing, Phone, DMV inquiry if DL suspended, Child Support if applicable, Supervision info) and weekly SkillCat module progress.
   - *Conditional Medical Rule:* **Never** ask if the participant needs medical appointments if their Briefcase indicates no chronic health conditions requiring treatment/medication.
3. **Part 3: LS/CMI Brief & Action Plan Target Alignment + Feedback Loop Check (5 min)**
   - Pull the active criminogenic target from the participant's LS/CMI Case Brief and Action Plan (`action_plan.md`).
   - **Feedback Loop Check:** Confirm the participant agrees with working on today's Action Plan target. If the participant disagrees or resists, execute the **Action Plan Feedback Loop** (acknowledge autonomy, connect to their 8-week employment/life goals, pivot to an alternate agreed target or offer a choice of two tools, and update `action_plan.md`).
4. **Part 4: Cognitive-Behavioral Skill / Tool Kit Intervention & Practice (10–15 min)**
   - Connect the participant's current issue to internal thinking ($S \rightarrow T \rightarrow A \rightarrow C$, Inside vs. Outside triggers/consequences).
   - Complete or practice one concrete tool from `Tool Kit 26.01.01_Final.pdf` (e.g., Decision Making Tool 1A, Timeline 1B, Upgrading Beliefs 1D, Thought Tracker 1G, STAC 1I/1K, Conflict Cycle 1M, Problem Solving 1N) or a `CBT with JICs` role play (*Two Voices Role Play*).
5. **Part 5: Concrete Next-Week Action Steps / Splashmap (3–5 min)**
   - Agree on 1–3 realistic, verifiable action steps before the next session (using SYNAPSE Splashmapping: Good Ripples vs. Bad Ripples, low step count, clear review day).
6. **Part 6: Apricot Case Note Documentation**
   - Document Session Type, Themes Discussed, Narrative Summary, Action Items Completed, New Action Items Assigned, and Next Meeting Focus.

## 2. Template Adherence Evaluation Checklist (How Well They Followed the Template)
When evaluating a Case Management session transcript, evaluate each of the 6 template sections as **`Followed Well`**, **`Partially Followed`**, **`Missed`**, or **`Not Applicable`**, with a verbatim transcript quote (`[MM:SS]`) and specific coaching on:
- **What They Did Well (Do's Observed)**
- **How They Can Improve (Don'ts / Missed Template Steps & Scripted Micro-Rewrites)**
- **Action Plan Feedback Loop Compliance:** Did the participant express disagreement with their Action Plan? If yes, did the case manager use the collaborative feedback loop instead of arguing or forcing compliance?
- **SYNAPSE & Script Adherence:** Did the case manager use Situated Empathy, Yielding, Navigating Dissonance, and the official First Shift conversation scripts?
